Инструкция для сервиса @V_Network_Solutions_bot Нажмите, чтобы перейти в основного бота →
1. Установка (Debian/Ubuntu)
wget https://github.com/hiddify/hiddify-next/releases/latest/download/hiddify-linux-x64.deb

sudo dpkg -i hiddify-linux-x64.deb
Альтернатива (Arch Linux)
yay -S hiddify-next
2. Запуск и Настройка

1. Скопируйте ключ в боте.

2. Запустите программу командой:

hiddify

3. Нажмите Add Profile → From Clipboard.

4. Настройте параметры сети (Region: Russia, DNS: 77.88.8.8) аналогично инструкции Windows.

5. Нажмите Connect.
