## [2026-10-01]

### Changed
- Windows 10/11: установка из одного файла `OshaVPN-windows.exe` без распаковки архива.
- Android и Windows переписаны под свой клиент OshaVPN: скачивание по кнопке из бота, добавление ссылки подписки («Вставить» → «Сохранить»), разрешения «Почти готово», режим «Россия напрямую» по умолчанию, встроенная проверка «Не работает? Проверить».
- В windows.html добавлен раздел для Windows 7 (якорь `#win7`).
- iPhone и iPad: вместо Happ — OneXray (Happ, v2RayTun, Streisand убраны из российского App Store).

### Fixed
